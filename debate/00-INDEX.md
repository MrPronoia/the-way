# Debate Cards — Index

One card per contested topic. Each card: the claim as we'd state it on stage, the strongest primary-source evidence, the objections an apologist will actually raise (with rebuttals), sound bites, and pointers into the repo for going deeper live.

**Ground rule:** every quote on these cards is cited to primary sources per the repo hierarchy (red text → Thomas → early non-canonical → DSS → Didache/Clementines → Ethiopian canon → scholarship). Podcast transcripts are never the source.

| Card | Question |
|---|---|
| `blood-atonement-and-salvation.md` | Does God need blood to forgive? What actually saves? |
| `pauls-legitimacy.md` | Is Paul a reliable source for what Jesus taught? |
| `trinity-deity-of-jesus.md` | Did Jesus claim to be God? |
| `rapture-end-times.md` | Is the rapture biblical? |
| `hell-afterlife.md` | Did Jesus teach eternal conscious torment? |
| `essene-nazarene-origins.md` | Where did Jesus's movement come from? |

| `sacrifice-culture-vegetarian-jesus.md` | Did Jesus oppose the sacrifice system? |
| `resurrection.md` | What does the resurrection evidence actually support? |
